Yayınlama & Deployment Rehberi
1. Anlık (Ücretsiz): Cloudflare Pages
1. GitHub'a yeni private repo oluştur: abap-analyzer-pro
2. index.html dosyasını repo'ya yükle
3. cloudflare.com/pages → "Connect to Git" → repo'yu seç
4. Build: yok (static HTML), Output: / (root)
5. Deploy → Otomatik HTTPS: https://abap-analyzer.pages.dev
6. Cloudflare Access → Zero Trust → Applications → Add → Self-hosted → @şirketin.com kısıtı
2. Kurumsal (~5€/ay): Vercel + Custom Domain
1. vercel.com → Import Git Repository
2. index.html → /public/index.html, vercel.json ekle:
  {"rewrites": [{"source": "/(.*)", "destination": "/public/index.html"}]}
3. Domain ayarları → DNS → CNAME kaydı
4. CI/CD otomatik — her push'ta deploy
3. Azure AD Entegrasyonu (Şirket SSO)
1. Azure Portal → App Registrations → New Registration
2. Redirect URI: https://senin-domain.com
3. Azure Static Web Apps → Link GitHub repo
4. Authentication provider: Azure Active Directory
5. Şirket hesabıyla tek tıkla giriş
