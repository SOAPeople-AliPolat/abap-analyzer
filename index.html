🗺 Ekip Paylaşım Yol Haritası
1. Şu An — HTML Dosyası ile Paylaşım (Hazır)
✓ Hemen kullanılabilir. abap_analyzer_pro.html dosyasını ekip üyelerine e-posta, Teams veya SharePoint üzerinden paylaşın. Her kullanıcı kendi tarayıcısında açar.

Adımlar:
1. Bu sayfadan HTML dosyasını indirin
2. Ekip klasörüne (Teams/SharePoint/OneDrive) yükleyin
3. Modül danışmanlarına linki gönderin
4. Admin olan danışman ZIP yükler → Herkes persistent storage üzerinden görür

⚠ Sınır: Persistent storage aynı Claude.ai oturumunda çalışır. Farklı oturum = farklı storage.
2. Kısa Vade — Statik Web Sunucu (1-2 gün)
HTML dosyasını bir web sunucuya koyun. Herkes URL ile erişir, local storage her kullanıcının kendi tarayıcısında kalır.

Seçenekler:
• GitHub Pages: Ücretsiz, repo'ya push → https://kullanici.github.io/abap-analyzer/
• Azure Static Web Apps: SOA People Azure aboneliği varsa 5 dakikada deploy
• SharePoint Embedded: SharePoint sayfasına iframe olarak gömün
• IIS/Apache: Şirket sunucusuna dosyayı kopyalayın, hepsi bu

ℹ Bu aşamada analiz sonuçları paylaşılır, aksiyon kararları kişisel kalır.
3. Orta Vade — Backend ile Gerçek Çok Kullanıcı (1-2 hafta)
Basit bir Node.js/Express veya Python/FastAPI backend ekleyin. Tüm ekip aynı veriyi görür, kararlar merkezi kaydedilir.

Mimari:
• Backend: Node.js + SQLite (veya PostgreSQL) — paket meta, obje kararları, yorumlar
• Frontend: Mevcut HTML + fetch() ile API çağrısı
• Auth: SAP SSO (SAML/OAuth2) veya basit JWT
• Deploy: Docker container → Azure App Service veya şirket sunucusu

Gerekli API endpointleri:
POST /api/packages — paket yükle
GET /api/packages — liste
PUT /api/objects/:name — aksiyon güncelle
POST /api/objects/:name/comment — yorum
POST /api/objects/:name/analyze — AI analiz
🏫 Modül Danışmanları İçin Kullanım Kılavuzu
Viewer rolü ile:
• Sol ağaçtan modülünüzü seçin (ZPP, ZMM, ZFI...)
• Her objenin "Özet" sekmesinde amacını ve ne işlem yaptığını okuyun
• "İhlaller" sekmesinde teknik sorunları görün (ABAP bilgisi gerekmez)
• "AI Analiz" sekmesinde anlaşılır Türkçe açıklamayı okuyun
• "Yorumlar" sekmesinde iş gereksinimleri notu bırakın

Consultant rolü ile (ek yetkiler):
• Her obje için "Kullan / Refactor / Yeniden Yaz / At" kararını verin
• AI Analiz butonuna tıklayarak kod açıklaması alın
• Rename önerilerini onaylayın (Değişiklikler sekmesi)

Admin rolü ile (tüm yetkiler):
• abapGit ZIP yükleyin — tüm ekip görebilir
• Onaylanan değişikliklerle yeni ZIP indirin — SAP'a yükleyin
